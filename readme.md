Repo containing some Technical Analysis tools for Python. Meant for Demonstration, Technical Analysis, or Tinkering; nothing here should be taken as direct Buy/Sell Recommendations.

The scripts are a version of the Bollinger Band Breakout strategy which I first learned about from Nick Radge's Unholy Grails. The Python version has some tweaks of my own, and the Repo contains a Monte Carlo test as well.

There's Pinescript versions as a bonus.

Running the Python script will require setting the Files and Folder to match your system.

The Pinescript can be run in Tradingview. Copy/paste the code into an empty script, or find them on my Tradingview ('Comatus') as 'Bollinger Bands Breakout Strategy' and 'Keltner Channel Breakout Strategy' and add them to your chart.
